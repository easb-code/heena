# Postmark mail dashboard

A responsive, interactive mail-dashboard prototype built with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a modern browser. No build step or dependencies are required.

## Demo behavior

- Browse the sample inbox, starred messages, and Work, Personal, and Travel labels.
- Filter by unread messages or attachments and search the sample mail.
- Open a message, toggle its star, archive it, or open a reply.
- Compose a demo message. Sent messages are kept in page memory only and are not delivered.

This is a front-end prototype. It does not connect to a Gmail, Outlook, or other mail account.
